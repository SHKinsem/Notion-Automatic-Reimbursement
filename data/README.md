# Data 文件夹说明

## 概述

本文件夹存储从 Notion 团队工作区导出的报销相关数据，包含采购项目的详细信息。

## 文件来源与结构

所有数据文件都来自 Notion 的报销文档。数据包含两种格式：

- **Markdown 格式**（`.md` 文件）：存储采购项目的详细信息（如物料规格、型号、单价等）
- **CSV 格式**（`.csv` 文件）：存储结构化的数据表格，便于后续处理和分析

## 如何从 Notion 导出数据

### 导出步骤

1. **打开 Notion 工作区**
   - 进入团队工作区中的报销相关文档

2. **导出数据表**
   - 点击表格右上方的 "···" 菜单
   - 选择 **Export** 选项

3. **配置导出设置**
   - **格式**：选择导出格式
     - 勾选 **Markdown & CSV** 以同时导出两种格式
   - **选项**：
     - ✅ **Include sub-pages**（包含子页面）- **重要**：必须勾选此选项以获取完整的层级数据
     - 其他选项按需选择

4. **保存文件**
   - 将导出的文件提取到本文件夹
   - 根据文件格式分别组织

## 文件命名规则

- 采购项目的 Markdown 文件以项目名称和 ID 命名
- 汇总表格存储为 `Reimbursement_xxx.csv` 格式

## 数据更新

当 Notion 中的报销数据更新时，请重新导出并替换本文件夹中的对应文件。
